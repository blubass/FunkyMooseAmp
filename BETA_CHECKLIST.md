# 🩺 Funky Moose - Beta Test Checklist

Bitte fülle diesen Bogen nach deiner Test-Session aus, oder nutze ihn als Leitfaden.

## 1. Erster Eindruck (UI/UX)
- [ ] Lädt das Plugin schnell?
- [ ] Ist die Oberfläche auf deinem Monitor scharf und gut lesbar?
- [ ] Verstehst du die Funktionen der Knöpfe ohne Anleitung?
- [ ] Windows/Reaper/Waveform: UI vergrößern, Plugin-Fenster schließen, erneut öffnen. Bleibt die Größe erhalten?

## 2. DSP & Sound
- [ ] **Tuner:** Reagiert er schnell genug auf tiefe Saiten?
- [ ] **Smart Gate:** Arbeitet es unauffällig (kein "Klicken")?
- [ ] **Amp:** Wie gefällt dir die Röhrensättigung (Tube Sat)?
- [ ] **Effekte:** Klingen sie im Mono- und Parallel-Modus druckvoll?
- [ ] **Chorus XOVER:** Bleibt der Bassbereich stabil, wenn der Chorus aktiv ist? Teste 120 Hz, 180 Hz und 300 Hz.
- [ ] **Boxen:** Welches Cabinet (1-4) ist dein Favorit?

## 3. Performance
- [ ] Gab es Audio-Aussetzer (Glitches)?
- [ ] Wie hoch ist die CPU-Last in deiner DAW?
- [ ] Funktioniert der Mono Maker wie erwartet (festerer Bassbereich)?

## 4. Sonstiges
- [ ] Hast du Bugs gefunden? Wenn ja, bei welcher Einstellung?
- [ ] Welches Feature fehlt dir noch für den perfekten Gig?
- [ ] Werden die Mädels/Jungs in der ersten Reihe durch das Plugin noch attraktiver?

Vielen Dank! Deine Hilfe ist unbezahlbar. 🦌💪
