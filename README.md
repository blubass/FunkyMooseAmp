## 🇬🇧 English

### Installation
For detailed instructions, see [INSTALL_GUIDE_EN.txt](INSTALL_GUIDE_EN.txt).\
*Note: The Windows standalone version uses the same iconic Moose icon as the macOS version.*

### Concept
Funky Moose Amp focuses on:
- Fast transient response
- Clean core tone
- Tight, controlled low end
- Mix-ready articulation

The goal is simple: **great feel under the fingers.**

### Modules
- Amp / Tone (clean base + musical EQ)
- VCA-style Compressor (fast attack, Punch mode, optional auto-makeup)
- Octaver, Envelope Filter, Chorus, Phaser
- Master section (Tuner, Mono-Maker, Gate)
- Cab section with selectable options + optional tube-style saturation

### Beta Feedback
I'm especially interested in:
1. Playability & dynamics
2. Input gain behavior (active vs passive basses)
3. CPU usage & oversampling
4. Workflow clarity

Report issues here:
https://github.com/blubass/FunkyMooseAmp/issues

### Security / Privacy
- Fully offline / No network access
- No telemetry or tracking
- Standalone may request microphone permission on macOS for live audio.

### Konzept
Der Funky Moose Amp legt den Fokus auf:
- Schnelle Transienten
- Klaren Grundsound
- Straffen, kontrollierten Bassbereich
- Gute Durchsetzungsfähigkeit im Mix

Ziel ist ein direktes und musikalisches Spielgefühl.

### Module
- Amp / Tone (cleaner Grundsound + musikalischer EQ)
- VCA-inspirierter Compressor (schnelle Attack, Punch-Modus, optional Auto-Makeup)
- Octaver, Envelope Filter, Chorus, Phaser
- Master (Tuner, Mono-Maker, Gate)
- Cab-Sektion mit wählbaren Optionen + optionaler Röhren-Sättigung

### Sicherheit & Privatsphäre
- Komplett offline / Kein Netzwerkzugriff
- Keine Telemetrie oder Tracking
